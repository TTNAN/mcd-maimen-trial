# 麦门审判 · mcd-maimen-trial

> 你说你是麦门信徒？让数据说话。

麦当劳程序员创意开发大赛参赛作品。把**麦门浓度测试**（quiz 答题）和**订单人格审判**（真实历史订单行为分析）结合在一起：

- 7 道麦门知识题：巨无霸几层肉饼？1+1 随心配多少钱？答错直接开嘲讽。
- 3 道习惯题：频率、本命单品、深夜记录。
- 接入麦当劳官方 MCP 拉取你的**真实历史订单**：时段分布、本命单品、客单价、白嫖记录，一个都跑不掉。
- 综合裁决：段位（麦门路人 / 信徒 / 长老 / 祖师）+ 人格标签（深夜党 / 薯条教 / 白嫖怪 / 钉子户……）+ 一句毒舌判词 + 分享卡。

最有意思的是**反差梗**：题全对但一单没点过 → 「嘴强王者」；题答得稀烂但订单拉满 → 「身体很诚实」。

## 在线试玩

👉 **https://ttnan.github.io/mcd-maimen-trial/** —— 手机打开就能玩，不用登录、不用 Token：10 道题出段位 + 毒舌判词，一键生成分享卡。

想用真实订单审判（反差梗更准），用下面的完整版接入麦当劳官方 MCP。

## 示例

[`sample_report.html`](sample_report.html) —— 脱敏示例报告（浏览器打开即可查看，可截图分享）。

## 运行

```bash
# 1. 去 https://open.mcd.cn/mcp 用手机号登录，点"激活"拿到 Token
# 2. Token 只走环境变量，不会写入任何文件
MCD_MCP_TOKEN=你的token python trial.py
```

也可以只答题不拉订单（跳过行为分析）：

```bash
MCD_MCP_TOKEN=你的token python trial.py --no-orders
```

## 目录结构

```
├── trial.py            # 主流程：答题 → 拉订单 → 分析 → 裁决 → 分享卡
├── quiz.json           # 题库（7 道知识题 + 3 道习惯题）
├── src/
│   ├── mcp.py          # 麦当劳 MCP 通用客户端
│   ├── analyzer.py     # 订单行为分析引擎
│   ├── personas.py     # 段位 / 反差梗 / 毒舌判词规则
│   └── report.py       # 分享卡 HTML 生成
├── sample_report.html  # 脱敏示例报告
├── MCP_INTEGRATION.md  # MCP 接入说明
└── CONTEST_DECLARATION.md
```
